# architasukhwani.github.io

Personal portfolio site for Archita Sukhwani, built as a static single-page site (HTML/CSS/JS, no build step) and hosted on GitHub Pages.

Content is sourced from Archita's resume ([uploads/Archita_Sukhwani_Resume.pdf](uploads/Archita_Sukhwani_Resume.pdf)).

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
```

## Deploy

Pushing to `main` is served automatically at `https://architasukhwani.github.io` via GitHub Pages.
